# GestionaTurnos

GestionaTurnos es una aplicación web destinada a facilitar la organización de los turnos de trabajo en supermercados.

Permitirá gestionar empleados, secciones, turnos y ausencias, además de generar automáticamente cuadrantes semanales que las encargadas podrán revisar y modificar.

Los empleados también podrán acceder a la aplicación para consultar sus horarios de trabajo.

## Tecnologías previstas

- Base de datos: MySQL.
- Backend: Laravel (PHP).
- Frontend: React.
- Alojamiento cloud: AWS.
