# GestionaTurnos

GestionaTurnos es una aplicación web destinada a facilitar la organización de los turnos de trabajo en supermercados.

Permite gestionar empleados, secciones, turnos y ausencias, además de generar automáticamente cuadrantes semanales que las encargadas pueden revisar y modificar.

Los empleados también pueden acceder a la aplicación para consultar sus horarios de trabajo.

## Tecnologías previstas

- Base de datos: MySQL.
- Backend: Laravel (PHP).
- Frontend: React.
- Alojamiento cloud: AWS.
